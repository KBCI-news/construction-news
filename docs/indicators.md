# 경제지표 데이터 출처

뉴스룸에 붙는 숫자는 게시판에 그대로 인쇄되므로 정확도가 최우선이다.
지표는 두 경로로 채워지며, **기관 원본이 있으면 항상 기관 원본이 이긴다**.

| 경로 | 표기 | 신뢰도 | 채우는 곳 |
| --- | --- | --- | --- |
| 기관 원본 통계 | `한국은행` 등 기관명 | 원본 그대로 | `/api/cron/ecos` |
| 기사 자동 추출 | `기사 추출` | 문맥 규칙으로 걸러낸 값 | `/api/cron/score`, `/api/cron/indicators` |

`indicators.source_kind = 'official'`인 지표는 기사 추출 크론이 건드리지 않고,
화면에서도 과거에 쌓인 기사 추출 점을 시계열에서 제외한다. 근거가 다른 값이
한 선 위에 놓이면 추이를 잘못 읽게 되기 때문이다.

## 1. 한국은행 ECOS (적용됨)

- 신청: <https://ecos.bok.or.kr/api/#/AuthKeyApply> — 무료, 즉시 발급
- 환경변수 `ECOS_API_KEY` (Vercel Production/Preview에 등록)
- 키가 없으면 `/api/cron/ecos`는 즉시 `skipped`를 반환하고 기존 기사 추출 방식이
  그대로 동작한다. 즉 **키 등록 전에도 서비스는 정상**이다.

현재 연결된 계열:

| 지표 | 통계표 | 항목 | 주기 | 구간 |
| --- | --- | --- | --- | --- |
| 기준금리 | `722Y001` | `0101000` | 일→월 다운샘플 | 최근 2년 |
| 가계대출 연체율 | `901Y124` 은행대출금 연체율(1개월 이상) | `MO3AB`(가계) × `AB`(은행전체) | 월 | 최근 24개월 |

`901Y124`는 (대출유형)×(은행구분) 2차원 표다. 항목을 하나만 지정하면
은행구분 3계열이 섞여 들어오므로 반드시 두 개를 고정한다.
총대출(전체) 항목은 이 표에 없어 **은행 연체율·카드·저축은행 연체율은
기사 추출로 남긴다** — 은행 전체·카드사·저축은행 연체율의 원본은 금감원
보도자료/FISIS(분기)인데, FISIS 보도자료 집계표(SA052 등)가 요구하는
집계 financeCd를 OpenAPI가 노출하지 않는다(개별사 코드는 `101` 거부,
companySearch 전 권역 스캔에도 집계 항목 없음). 금감원 발표 기사가
나오면 그때 값이 채워진다.

계열을 추가할 때는 코드를 추측하지 말고 조회 모드로 확인한다.

```
curl -H "Authorization: Bearer $CRON_SECRET" \
  "$SITE/api/cron/ecos?discover=연체율"     # 통계표 코드 검색
curl -H "Authorization: Bearer $CRON_SECRET" \
  "$SITE/api/cron/ecos?items=722Y001"       # 세부항목 코드 목록
```

확인한 코드를 `src/lib/ecos.ts`의 `ECOS_SERIES`에 추가한다. 각 계열은
`expectName`/`expectUnit`으로 응답의 통계명·단위를 다시 검증하므로, 코드가
개편되거나 잘못 적히면 값을 쓰지 않고 크론 응답에 사유를 남긴다.

ECOS에서 받을 수 있는 것 중 우리 업무와 가까운 계열: 예금은행 가계대출 금리,
가계신용 잔액, 어음부도율, 소비자물가. 기준금리와 달리 코드 확인이 필요해
키 등록 후 `discover`로 잡아 넣는 것이 안전하다.

## 2. 금융감독원 금융통계정보시스템(FISIS) — 연체율의 정답지

- 신청: <https://fisis.fss.or.kr/fss/fsiview/indexW.html> OpenAPI 인증키 (무료)
- 은행·카드사·저축은행의 **연체율·고정이하여신비율**을 업권/회사 단위로 제공한다.
  지금 기사에서 뽑고 있는 `bank_delinq` / `card_delinq` / `savings_delinq`의 원본이
  바로 이 통계다.
- 분기 공시라 발표 시차가 2~3개월 있다. 대신 값이 정확하고 결측이 없다.
- 도입하려면 회사코드(`financeCd`)와 통계표번호(`listNo`)를 조회 API로 먼저
  확정해야 한다. ECOS와 동일한 구조로 `src/lib/fisis.ts`를 추가하면 된다.

## 3. 그 밖에

- **KOSIS 공유서비스** (<https://kosis.kr/openapi/>) — 통계청 경유로 같은 지표를
  받을 수 있으나 ECOS/FISIS 원본보다 갱신이 느리다.
- **공공데이터포털** (<https://www.data.go.kr>) — 기관별 API가 흩어져 있고 품질 편차가
  크다. 위 두 곳으로 못 얻는 지표가 생길 때만 본다.
- **한국은행 오픈API 100건/일 제한 없음** — 크론 30분 주기(48회/일)로 충분히 여유.

## 운영 메모

- 마이그레이션 `0007_indicator_source_kind.sql` 적용이 선행되어야 `source_kind`가
  동작한다. 미적용 상태에서도 모든 라우트는 한 단계 물러서서 기존 스키마로 돌아간다.
- 지표 카드는 링크가 아니다. 추이를 보려고 누른 손가락이 외부 기사로 튀면
  보던 목록 위치를 잃기 때문에 클릭 동작을 두지 않는다.
