공통 파이프라인

모든 태그는 같은 수집·판정 결과 위에서 조건만 달리 걸어 보여준다.

  1. 수집수집 쿼리로 지정된 키워드만 네이버 뉴스 API를 호출한다. 핵심(T0) 30분, 관련(T1) 2시간, 주변(T2) 6시간 주기.
  2. 데스크 태깅기사 제목 기준으로 키워드를 매칭해 데스크(주제 축)를 붙인다. 핵심·관련 키워드는 단독 인정, 주변 키워드는 같은 데스크 근거가 더 있어야 인정. 홍보성 기사는 자사 관련만 남긴다.
  3. 사건종류 판정행위성 사전(아래)으로 "무슨 일이 일어났는가"를 판정한다 — 감독·제재 / 입법·개정 / 판결 / 시장·거래 / 지표·통계. 법/정책 태그가 이 축을 쓴다.
  4. 중복 제거같은 사건을 다룬 기사들을 묶어 대표 1건만 노출한다(전일 기사와도 비교).
  5. 피드태그 조건 + 기간(1일/1주/1달/전체) + 정렬(기본 최신순)으로 조회한다.

태그별 조건과 키워드

키워드는 두 종류다. 수집 쿼리는 네이버 검색을 실제로 도는 말, 판정 전용은 이미 수집된 기사를 태깅할 때만 쓰는 말. 판정 전용을 수집 쿼리로 올리면 그 키워드의 기사가 더 빨리·더 많이 들어온다.

핵심 T0 업무 최근접 — 30분 주기 수집 관련 T1 2시간 주기 ● 표시 = 수집 쿼리 · 없으면 판정 전용

표기 규칙과 미노출 축

  • 카드 알약 — 태그를 골라 보는 중엔 카드도 그 태그 라벨로 표기한다. 전체·검색 화면에서는 기사 자체의 데스크를 보여준다.
  • 정보보호 제외 — 개인(신용)정보 보호·유출·마이데이터 축(creditinfo)은 태그 체계에서 빠졌고 카드에도 표기하지 않는다. 수집·판정은 유지 중이라 언제든 되살릴 수 있다.
  • 태그 없이 돌아가는 축 — 채무자보호(개인회생·채무조정), 부실채권(NPL·연체율), 대출(가계대출·규제), 노동, 거시(기준금리)는 태그로 노출되지 않지만 수집·중요도 판정과 법/정책 태그의 재료로 쓰인다.
  • 검색 — 검색어가 있으면 제목·요약 부분일치로 자체 아카이브(30일)를 뒤지고, 정렬 기본이 관련도순으로 바뀐다.
